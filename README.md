# Sales Performance Analysis — Superstore

## 1. Business Objective
Menganalisis performa penjualan Superstore berdasarkan tren waktu, kategori produk, wilayah, dan segmen pelanggan untuk mendukung pengambilan keputusan bisnis.

## 2. Data Preparation
Dataset berisi 9.994 baris dan 21 kolom. Data diperiksa melalui proses validasi tipe data, missing values, duplikasi, dan konsistensi tanggal. Data hasil cleaning digunakan untuk analisis lebih lanjut.

## 3. Key Findings

- **Sales Trend:** Penjualan tertinggi terjadi pada September 2016, dengan total $24,631M. Pola penjualan menunjukkan peningkatan tajam di bulan tersebut.
- **Category Performance:** Kategori dengan kontribusi penjualan terbesar adalah Furniture, dengan total penjualan $551,405M.
- **Regional Performance:** Wilayah dengan penjualan tertinggi adalah Barat, sedangkan wilayah dengan penjualan terendah adalah Selatan.
- **Customer Segment:** Segmen dengan kontribusi penjualan terbesar adalah Consumer.

## 4. Business Recommendations

- Mengevaluasi pola penjualan bulanan untuk membantu perencanaan stok dan promosi.
- Meninjau kontribusi kategori produk untuk menentukan prioritas pengembangan penjualan.
- Membandingkan performa antarwilayah untuk menemukan peluang peningkatan penjualan.
- Menggunakan analisis lanjutan untuk mengevaluasi profitabilitas dan efektivitas diskon.
